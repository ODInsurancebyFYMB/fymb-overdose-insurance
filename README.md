# FYMB Overdose Insurance — GitHub Pages website

A static, no-build, no-Supabase website with a matching black/purple design across five pages.

## Upload
1. Extract this ZIP.
2. In your GitHub repository, upload **all five HTML files** to the repository root (not inside a folder). Replace the old `index.html`.
3. In Settings → Pages, select Deploy from a branch, `main`, `/ (root)`.
4. Wait for deployment, then hard-refresh the live website.

## Pages
- `index.html` — policy cards, capped selectors, payment instructions
- `lotto.html` — FYMB LOTTO rules
- `how-it-works.html` — payment and claims instructions
- `terms.html` — terms and coverage rules
- `contact.html` — FYMB Torn profile link

No payment is sent automatically. Customers must enter payment information inside Torn. There is no automatic payment verification.

## Future edits
Open any HTML file on GitHub and use the pencil icon. Change text inside HTML tags, then Commit changes. For policies, edit the `policies` array near the bottom of `index.html`. Make a backup before changes.
